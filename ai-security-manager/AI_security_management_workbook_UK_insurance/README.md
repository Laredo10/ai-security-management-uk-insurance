\# Populated workbook — UK insurer AI Security Management



This folder holds the populated workbook used as the single

source of truth for the gap-check and the interview deck. The

workbook was rebuilt from the supplied summary document after

the original .xlsx was returned as a 59-byte placeholder by the

CDN. Content is evidence-based, not invented.



\## What is in this folder



\- 01-workbook-populated.xlsx — the populated workbook. 32 sheets

&#x20; covering governance, model risk, operational resilience,

&#x20; third-party risk, IAM, cloud security, incidents, services,

&#x20; financial analysis, implementation roadmap, business

&#x20; continuity, reference data, and ID glossary.

\- workbook-summary.md — the per-sheet extract that fed the

&#x20; rebuild. Use this as a faithful summary of every sheet's

&#x20; structure, headers, and sample rows.



\## What the 32 sheets cover



The workbook is structured as a regulated AI management system

aligned to the UK insurance regime. Sheets are grouped by

domain:



Strategic oversight: Board Dashboard, Board Pack Notes, Board

KPI-KRI Tracker, TOM and Strategy, TOM Index. Owners are the AI

Security Manager, the Chief Risk Officer, and the Chief

Operating Officer. Cited by FWK-01 (FCA SYSC), FWK-02 (FCA

Consumer Duty), FWK-06 (ISO/IEC 42001), FWK-07 (NIST AI RMF),

FWK-09 (PS21/3), FWK-10 (SM and CR).



Core inventory: AI Use Case Register, Governance Framework,

RACI Matrix. The use-case register is the single source of use-

case truth. Cited by FWK-03 (PRA SS2/21), FWK-04 (ICO UK GDPR),

FWK-05 (EU AI Act), FWK-11 (IDD and ICOBS).



Risk and control: Management Review and Internal Audit,

Dashboard, Executive Report, Risk Quantification, Incident

Analysis, Compliance Mapping, Maturity Assessment. Cited by all

eleven regulatory frameworks.



Operational: Service Catalog Master, SLA-SLO Definitions,

Service Request Log, KRI Tracking, KPI Tracking, Technology

Stack, Automation Hub, Cloud Security Services, IAM Services,

Metrics Calculation Guide, Reference Data, ID Glossary.



Planning and finance: Resource Planning, Financial Analysis,

Implementation Roadmap, Business Continuity.



\## How to use this folder



Open 01-workbook-populated.xlsx to walk the evidence end-to-end.

Use workbook-summary.md when you need a printable narrative of

what each sheet contains and which regulatory section it

anchors to.
