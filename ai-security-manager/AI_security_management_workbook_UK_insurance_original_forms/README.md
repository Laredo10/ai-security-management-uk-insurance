\# Template workbook — original form tabs



This folder holds the template workbook used to author the

populated workbook in the sibling folder. The template defines

form tabs that are filled in by the AI Security Manager on a

fresh engagement.



\## What is in this folder



\- 02-workbook-template.xlsx — the template workbook. Holds the

&#x20; form tabs for populating on a fresh engagement. Used to author

&#x20; the populated workbook.

\- template-summary.md — the per-tab extract that fed the

&#x20; rebuild. Use this as a faithful summary of every form tab's

&#x20; structure, headers, and sample rows.



\## What the form tabs cover



Eighteen of the form tabs map one-to-one to populated sheets in

the sibling folder:



Form AI Use Case → AI Use Case Register.

Form Risk Quantification → Risk Quantification.

Form KRI Tracking → KRI Tracking.

Form KPI Tracking → KPI Tracking.

Form Incident Analysis → Incident Analysis.

Form Third-Party Risk → Third-Party Risk Services.

Form Compliance Mapping → Compliance Mapping.

Form Service Catalog → Service Catalog Master.

Form SLA-SLO → SLA-SLO Definitions.

Form Service Request Log → Service Request Log.

Form Governance Framework → Governance Framework.

Form RACI Matrix → RACI Matrix.

Form Maturity Assessment → Maturity Assessment.

Form Implementation Roadmap → Implementation Roadmap.

Form Resource Planning → Resource Planning.

Form Financial Analysis → Financial Analysis.

Form Cloud Security → Cloud Security Services.

Form IAM Services → IAM Services.



The remaining populated sheets are narrative (author-written)

and assembled from the form tabs and the underlying operating

model.



\## How to use this folder



On a fresh engagement, copy 02-workbook-template.xlsx into a

working directory, populate each form tab from your environment,

and promote the resulting workbook into the populated folder.

Use template-summary.md to plan the population sequence.



\## Caveats



Tab layout is faithful. Field-level fidelity is approximately

85 percent. Sample values are placeholders unless overridden

during population.
